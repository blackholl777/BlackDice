# BlackDice Site

무료 공개 웹사이트. GitHub Pages로 호스팅합니다.

## 게시 방법

1. GitHub 저장소 → Settings → Pages
2. Source: Deploy from a branch
3. Branch: `main` / folder: `/ (root)`
4. Save 후 약 1분 뒤 `https://blackholl777.github.io/BlackDice/` 접속

## 광고 수익 (Google AdSense)

사이트가 실제로 돌고, 원고 글·개인정보처리방침이 있을 때 신청합니다.
승인 후 `index.html`의 `ADSENSE_CLIENT` 자리에 광고 코드를 넣으면 됩니다.
